# В ГОВНО

Развлекательный калькулятор чистого этанола для взрослых: складывает напитки, считает спирт, переводит его в эквивалент другого напитка, выдаёт шуточный вердикт и делает PNG-карточку с результатом.

**18+.** Это не медицинское приложение и не измеритель опьянения.

## Что умеет

- 10 категорий напитков: пиво, водка, вино, виски, коньяк, ром, коктейли, сидр, слабоалкогольные и «другой напиток».
- Произвольный объём (мл или литры), крепость и количество порций. Пресеты объёма от 30 мл до 1 л.
- Добавление, редактирование, удаление позиций и очистка списка с подтверждением.
- Расчёт объёма чистого этанола, его массы (плотность 0,789 г/мл) и общего объёма напитков.
- Конвертер в выбранный напиток с редактируемой крепостью и быстрыми переключателями.
- Блок «А ЧЁ У МЕНЯ ТАМ ПО КРОВИ?»: пол, вес, рост (не обязательно), время первого и последнего напитка, текущее время по системным часам и еда (сколько и когда).
- Расчётная концентрация алкоголя в крови в промилле, диапазон модели, стадия кривой (рост / пик / спад), пик, адаптивный SVG-график и ориентировочное время снижения до условного нуля.
- Семь авторских шуточных уровней с 9 фразами на каждый; фразы сменяются при повторном нажатии кнопки.
- Мем-карточка 1080 × 1350 PNG, сгенерированная на Canvas: скачивание файла и Web Share API с фолбэком на скачивание.
- Сохранение списка и настроек конвертера в LocalStorage.
- Адаптивная вёрстка для телефона, планшета и компьютера.

## Запуск

Нужен Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173/vkal/`).

```bash
npm run build     # production-сборка в dist/
npm run preview   # посмотреть собранную версию
npm test          # автотесты формул, крови, валидации, вердиктов и переноса текста
npm run typecheck # строгая проверка TypeScript
```

## Публикация

Приложение публикуется на GitHub Pages по адресу **https://kirilltolich.github.io/vkal/**.

В `vite.config.ts` задан `base: '/vkal/'`, поэтому стили и скрипты собираются с путями `/vkal/assets/...`.

Workflow [.github/workflows/deploy.yml](.github/workflows/deploy.yml) запускается при пуше в `main`:

1. устанавливает зависимости через `npm ci`;
2. собирает проект командой `npm run build`;
3. публикует содержимое `dist/` через GitHub Pages.

В настройках репозитория должен быть выбран источник **Settings → Pages → Build and deployment → Source: GitHub Actions**. После первого успешного запуска workflow сайт будет доступен по адресу выше.

Сервер, регистрация, база данных и платные API не нужны.

## Формулы

- Этанол одной позиции: `объём (мл) × крепость (%) / 100 × количество порций`.
- Масса этанола: `объём этанола (мл) × 0,789`.
- Эквивалент напитка: `суммарный этанол (мл) × 100 / крепость выбранного напитка (%)`.

Промежуточные значения не округляются, округление применяется только при отображении.

## Модель концентрации алкоголя в крови

Живёт в `src/utils/bac.ts`, параметры и допущения — в `src/data/blood.ts`.

- **Распределение (Видмарк).** `C = масса этанола в теле ÷ объём распределения`, где объём = коэффициент Видмарка × масса тела. Без роста берутся средние коэффициенты: 0,68 (мужчины) и 0,55 (женщины). С ростом коэффициент считается из общей воды тела по Hume–Weyers (1971) с поправкой на долю воды в крови (0,8) и ограничивается рамками 0,45–0,85.
- **Всасывание не мгновенное.** Этанол уходит из «желудка» кинетикой первого порядка с полувыведением около 12 минут; при еде — с коэффициентом 0,75 / 0,55 / 0,40 (закусил / нормально / плотно) в окне 2–4 часа. Поэтому кривая продолжает расти после последнего напитка, а еда после алкоголя не вычитает уже всосавшееся.
- **Выведение (Михаэлис–Ментен).** `v = Vmax × C ÷ (Km + C)`, `Km = 0,1 ‰`, при заметной концентрации это около 0,15 ‰ в час. Концентрация не уходит ниже нуля.
- **Диапазон** — та же модель при границах допустимых параметров: объём распределения ±12 %, скорость выведения 0,10–0,20 ‰/ч, полувыведение из желудка 8–18 минут. Это разброс параметров модели, а не доверительный интервал и не точность измерения.
- **Расписание.** Напитки из списка распределяются по указанному интервалу: первый — в момент начала, последний — в указанное время последнего напитка, остальные равномерно. Точного порядка у приложения нет.
- **Ноль.** Условный порог 0,01 ‰. Время достижения нуля — оценка модели, а не гарантия трезвости и не разрешение садиться за руль.

## Честность расчётов и безопасность

Уровни и их пороги — условные правила игры, а не медицинские степени опьянения. Крепость напитков по умолчанию — редактируемые примеры; для коктейлей и «другого напитка» ориентируйтесь на фактические данные.

Концентрация алкоголя в крови считается по приблизительной модели и **не является измерением**: реальную цифру показывает только анализ. Индивидуальные факторы (печень, гены, лекарства, усталость, состав тела) модель не знает, поэтому рядом с результатом всегда показывается диапазон модели, а время до нуля — как ориентир, а не как гарантия трезвости. Приложение нигде не пишет, что после употребления можно садиться за руль, и не использует юридические пороги как подтверждение безопасности.

При большом количестве этанола интерфейс показывает предупреждение: не продолжать пить, не садиться за руль, не оставлять человека одного. При потере сознания, нарушении дыхания или судорогах — звонить 112 или 103.
