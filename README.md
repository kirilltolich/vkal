# В ГОВНО

Развлекательный калькулятор чистого этанола для взрослых: складывает напитки, считает спирт, переводит его в эквивалент другого напитка, выдаёт шуточный вердикт и делает PNG-карточку с результатом.

**18+.** Это не медицинское приложение и не измеритель опьянения.

## Что умеет

- 10 категорий напитков: пиво, водка, вино, виски, коньяк, ром, коктейли, сидр, слабоалкогольные и «другой напиток».
- Произвольный объём (мл или литры), крепость и количество порций. Пресеты объёма от 30 мл до 1 л.
- Добавление, редактирование, удаление позиций и очистка списка с подтверждением.
- Расчёт объёма чистого этанола, его массы (плотность 0,789 г/мл) и общего объёма напитков.
- Конвертер в выбранный напиток с редактируемой крепостью и быстрыми переключателями.
- Семь авторских шуточных уровней с 9 фразами на каждый; фразы сменяются при повторном нажатии кнопки.
- Мем-карточка 1080 × 1350 PNG, сгенерированная на Canvas: скачивание файла и Web Share API с фолбэком на скачивание.
- Сохранение списка и настроек конвертера в LocalStorage.
- Адаптивная вёрстка для телефона, планшета и компьютера.

## Запуск

Нужен Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173/vkal/`).

```bash
npm run build     # production-сборка в dist/
npm run preview   # посмотреть собранную версию
npm test          # 44 автотеста формул, валидации, вердиктов и переноса текста
npm run typecheck # строгая проверка TypeScript
```

## Публикация

Приложение публикуется на GitHub Pages по адресу **https://kirilltolich.github.io/vkal/**.

В `vite.config.ts` задан `base: '/vkal/'`, поэтому стили и скрипты собираются с путями `/vkal/assets/...`.

Workflow [.github/workflows/deploy.yml](.github/workflows/deploy.yml) запускается при пуше в `main`:

1. устанавливает зависимости через `npm ci`;
2. собирает проект командой `npm run build`;
3. публикует содержимое `dist/` через GitHub Pages.

В настройках репозитория должен быть выбран источник **Settings → Pages → Build and deployment → Source: GitHub Actions**. После первого успешного запуска workflow сайт будет доступен по адресу выше.

Сервер, регистрация, база данных и платные API не нужны.

## Формулы

- Этанол одной позиции: `объём (мл) × крепость (%) / 100 × количество порций`.
- Масса этанола: `объём этанола (мл) × 0,789`.
- Эквивалент напитка: `суммарный этанол (мл) × 100 / крепость выбранного напитка (%)`.

Промежуточные значения не округляются, округление применяется только при отображении.

## Честность расчётов и безопасность

Уровни и их пороги — условные правила игры, а не медицинские степени опьянения. Крепость напитков по умолчанию — редактируемые примеры; для коктейлей и «другого напитка» ориентируйтесь на фактические данные. Приложение не определяет концентрацию алкоголя в крови, не рассчитывает время протрезвления и не говорит, что после употребления можно управлять транспортом.

При большом количестве этанола интерфейс показывает предупреждение: не продолжать пить, не садиться за руль, не оставлять человека одного. При потере сознания, нарушении дыхания или судорогах — звонить 112 или 103.
